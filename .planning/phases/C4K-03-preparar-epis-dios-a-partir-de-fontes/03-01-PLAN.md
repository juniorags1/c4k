# Objetivo
Automatizar libraryAdd → fonte 4K → qBittorrent → catálogo, servindo o próprio arquivo de done.

1. Configuração protegida, teste de conexão e intenções SQLite idempotentes; formulário manual para IMDb/episódio e magnet.
2. Resolver Torrentio e monitorar tarefas próprias via API. Persistir hash antes de enviar; recuperar por hash. Selecionar arquivo antes de iniciar download, publicar somente completo e fora de estados de movimentação/verificação.
3. Cadastro direto em done; remoção física apenas do arquivo cadastrado, desanexando tarefa própria sem exclusão de pacote. Bloquear arquivos compartilhados e tarefas externas.
4. Atualizar painel, contratos, documentação e testar com fixtures/mocks. Publicar executável preservando tokens e mídia existente; validar conexão real somente quando credenciais configuradas.

Revisão inline: decisão de exclusão destrutiva explicitamente autorizada pelo usuário; confirmação por item no painel. Sem download real ou exclusão de mídia real durante testes. Riscos: cliente pode não emitir libraryAdd; provedor indisponível ou seeds desatualizados; API exige senha. Esses estados devem ser visíveis e recuperáveis.
