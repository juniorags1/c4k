# Renomear projeto para C4K

1. Renomear solução, projeto/namespace/executável, scripts, variáveis, painel, addon e documentação; preservar UTF-8.
2. Registrar confirmação do usuário de reprodução na TV, mantendo critérios não relatados pendentes.
3. Publicar C4K, parar somente o host anterior, migrar diretório e SQLite com validação de caminhos e backup dos dados pequenos. Preservar tokens, mídia e URL.
4. Testar build, HTTP e binário publicado, incluindo compatibilidade do catálogo já salvo no Stremio; iniciar C4K e conferir dados reais.

Não renomear a pasta do workspace, metadados Git ou ferramentas GSD instaladas, que contêm caminhos absolutos de infraestrutura. Identificador antigo de catálogo fica apenas como alias de compatibilidade para clientes existentes.
