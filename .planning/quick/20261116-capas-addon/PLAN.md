# Capas no catálogo C4K

Tarefa GSD quick executada inline conforme adaptador Codex. Acrescentar poster e posterShape no catálogo e metadados, com URL HTTPS MetaHub derivada somente de IMDb válido. Sem consulta remota bloqueante por item, sem alteração de vídeos/tokens. IDs locais continuam sem associação presumida. Imagens dependem de internet/cache do cliente.

Validar contratos HTTP de filme, série e ID local; publicar preservando biblioteca e download corrente. Referência oficial: stremio-addon-sdk/docs/api/responses/meta.md. URL real de Bugonia respondeu HTTP 200 image/jpeg.
