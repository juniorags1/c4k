Automação com qBittorrent

Ao adicionar uma série à biblioteca do Stremio, prepara os dois primeiros episódios lançados. Para filmes, prepara o filme. Procura a fonte 4K com mais seeds informados pelo provedor.

A senha é protegida pelo Windows e não é devolvida ao navegador. Magnets são enviados pela API do qBittorrent, sem precisar de uma pasta monitorada.

Conclua as tarefas pendentes e coloque os arquivos cadastrados no novo local, mantendo as subpastas, antes de salvar. O C4K não move arquivos ou torrents existentes. Ajuste esses torrents no qBittorrent antes de retomar downloads.

Próximos episódios

Com a automação ativada, marcar um episódio como assistido prepara os dois seguintes, incluindo a próxima temporada. Episódios ainda não lançados aguardam uma nova consulta. Marque um episódio específico para indicar onde você parou.

Limpeza de assistidos

Filmes e episódios marcados como watched são apagados do disco e do catálogo após 72 horas. Marcar como unwatched cancela a limpeza. Vale para novas marcações recebidas pelo C4K, mesmo com downloads automáticos desativados. O PC precisa estar ligado. Pacotes compartilhados aguardam os outros itens vencerem; falhas são tentadas novamente em uma hora.

Eventos recebidos

Se a ação no Stremio não aparecer aqui, o cliente não enviou o evento. Marcar como não assistido não cancela downloads nem apaga arquivos. O início da reprodução sozinho ainda não dispara antecipação.
